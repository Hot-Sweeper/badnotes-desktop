# Changelog

## 0.1.0-alpha.2

First downloadable public alpha, with native Windows x64, Linux x64, and macOS
Apple Silicon/Intel build targets. Adds Debian maintainer metadata, portable data
paths, authenticated loopback startup, release checksums, and end-to-end packaged
desktop startup verification. See docs/RELEASE_NOTES.md for features and caveats.

## 0.1.0-alpha.1

Initial clean public source snapshot. The first release matrix caught missing
Debian packaging metadata; no downloadable release was published for this tag.
